# Agent Skills

Backup for Skills Manager data and my custom agent skills.

- `.skills-manager/` contains Skills Manager configuration and metadata.
- Each root folder containing a `SKILL.md` file is an installable skill.

Browse the catalog at [joshiminh.github.io/agent-skills](https://joshiminh.github.io/agent-skills), or install from GitHub:

```sh
npx skills add JoshiMinh/agent-skills --copy -y
```
